# 二〇二六
## Vitepress
现在是2025年12月31日，为了表示网站并没有宣告停更水一篇。又由于一般对一个博客网站而言，这个时候发文往往与年度总结与展望有关，所以标题直接改名叫二〇二六。~~实则并不觉得有什么值得总结与展望的。~~

从最近的说起，也是原本计划的文章主题———Vitepress。由于实在忍受不了Wordpress的数据库管理方式导致的加载速度过慢（当然主要和最初选择的主题有关），也是想尝试一下由本地文件部署的静态网页生成，我用Vitepress替代了原先的网站框架。最近依然在熟悉文件结构，也借机了解一下前端网页构建的过程。这似乎是一个持续性的工程，从文件结构的构建整理，前端的设计，功能的完善，再到服务器的维护监控……听起来好遥远，如果能持续做下去的话。所以现在看到与其他博客大佬的差距也就没那么大心理落差了（？）~~（明明连前端还一点都不懂，主页还是AI写的）~~

AI在学习上带来最直接的感受是学习门槛的降低与工程启动难度的降低。如今技术框架的更新迭代及其迅速，而AI使人不得不面临的真正问题其实是意义问题（即为什么而学习，正如class层面的问题本质上是意义层面的问题，而后者这个问题无关时代，无人陌生）。因此我依然存在一个奢望：一个我能够不追求特定目标，自由探索的奢望，尽管身处在强调效率与结果的学习环境与氛围中。

## 补充
最初的笔记在网站框架转移后准备移除，可能后面会放上期末周复习时的一些总结。几个月以来电脑里多装了几个开源软件，工作流也在慢慢摸索中。尽管长期计划没有，但短期内还是希望接触一下web知识与git。似乎没有别的想写的了，其实文章最后结束是在2026年第一天深夜，不知道新的一年熬夜次数会变多还是变少？
